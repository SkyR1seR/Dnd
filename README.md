# Лист персонажа D&D 5e (2014)

Веб-приложение: электронный лист персонажа по правилам «Книги игрока» 2014 г. и удобный
**игровой режим** для использования прямо за столом (в том числе с телефона).

## Возможности

**Лист персонажа**
- Несколько персонажей, копирование, импорт/экспорт в JSON
- Характеристики, спасброски, 18 навыков (владение, компетентность, «Мастер на все руки»)
- Автоматический расчёт: модификаторы, бонус мастерства, инициатива, пассивные навыки,
  Сл и бонус атаки заклинаниями, средние хиты
- Мультикласс: кость хитов, тип заклинателя и спасброски подставляются из шаблона класса
- Ячейки заклинаний считаются по таблице мультиклассирования, включая половинных/третьих
  заклинателей и магию договора колдуна (можно переопределить вручную)
- Атаки, ограниченные ресурсы (ярость, ки, …), заклинания, снаряжение и монеты, умения,
  личность и заметки

**Игровой режим**
- Броски проверок, спасбросков, навыков, инициативы и атак одним нажатием; урон (с удвоением
  костей при крите) прямо из результата атаки
- Преимущество / помеха; состояния и истощение автоматически влияют на броски
  (например, «Отравленный» даёт помеху, «Парализованный» — автопровал спасбросков СИЛ/ЛОВ)
- Хиты: урон (сначала снимаются временные хиты), лечение, временные хиты,
  спасброски от смерти, напоминание о спасброске концентрации с нужной Сл
- Ячейки заклинаний, сотворение с выбором ячейки (в т.ч. повышенной), ритуалы, концентрация
- Ресурсы, короткий отдых (трата костей хитов) и продолжительный отдых
- Свободный бросок кубиков (`2к6+3`, `1d8`), журнал бросков
- На телефоне — нижняя навигация по разделам

Данные хранятся в `localStorage` браузера.

## Источник правил

Правила и термины сверены с русским переводом «Книги игрока» D&D 5e (2014):
названия навыков и состояний, таблицы опыта, бонуса мастерства, ячеек мультикласса
и магии договора, правила отдыха, урона, спасбросков от смерти, временных хитов
и концентрации. Изобретатель — по «Котлу Таши». Навыки, которые в разных переводах
называются по-разному, показаны с обоими названиями: «Внимательность (Восприятие)»,
«Анализ (Расследование)». Тексты книги в репозиторий не копируются — описания
в примерах краткие, со ссылками на страницы.

## Запуск

```bash
npm install
npm run dev      # режим разработки
npm run build    # сборка в dist/ (можно разместить на любом статическом хостинге)
npm test         # юнит-тесты правил
```
